# Student Performance Analytics Portal

A modern, responsive web-based **Student Performance Analytics Portal** developed to manage, monitor, and analyze academic performance, attendance, assignments, courses, and student-related information.

The project provides dedicated interfaces for students and teachers, along with authentication, profile management, notifications, reporting, analytics, theme customization, and responsive user interfaces.

---

## 📌 Project Overview

The **Student Performance Analytics Portal** is an academic management and analytics web application designed to provide an organized platform for monitoring student performance.

The system allows users to access academic information through dedicated dashboards and provides useful tools for viewing performance statistics, attendance, assignments, courses, reports, and analytics.

The project was developed as part of an **internship project** with a focus on practical web development, responsive UI design, JavaScript functionality, data visualization, and user experience.

Before running the project, make sure the following tools are installed:

- Visual Studio Code

## 🧩 JavaScript Modules

The project uses separate JavaScript files to keep functionality organized and maintainable.

| File | Purpose |
|------|---------|
| `script.js` | Global UI functionality, navigation, common interactions, and page-level behavior |
| `theme.js` | Handles light/dark theme switching and theme persistence |
| `storage.js` | Handles browser-based data storage and retrieval |
| `auth.js` | Handles authentication-related functionality |
| `dashboard.js` | Handles dashboard interactions, search, refresh, and dashboard data |
| `charts.js` | Creates and manages performance analytics charts |
| `notifications.js` | Handles notifications, notification panel, search, and interactions |
| `profile.js` | Handles profile information, profile image upload, and profile settings |
| `github.js` | Handles GitHub-related portfolio functionality |
| `contact.js` | Handles contact-page interactions and form functionality |
